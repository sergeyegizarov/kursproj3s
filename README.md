
##  Описание проекта

Данный проект это серверная программа клиент-серверной системы обработки данных, разработанная в рамках курсовой работы по дисциплине «Технологии и методы программирования».

Программа реализует TCP-сервер, который:
- Принимает подключения от клиентов и проводит их аутентификацию.
- Получает от клиентов условные векторы значений типа `uint16_t` в бинарном формате.
- Вычисляет **среднее арифметическое** каждого вектора.
- Возвращает результат клиенту.
- При переполнении вверх возвращает значение **2¹⁶ − 1 (65535)**.

---

##  Функциональные возможности

-  Чтение базы пользователей при старте программы.
-  Обеспечение возможности подключения клиента в течение всего времени функционирования.
-  Обработка запросов клиентов в однопоточном режиме.
-  Идентификация и аутентификация подключаемого клиента (MD5 + соль).
-  Вычисление среднего арифметического вектора с защитой от переполнения.
-  Запись информации об ошибках в файл журнала.
-  Управление через параметры командной строки.
-  Работа в операционной системе с ядром Linux.

---

##️ Требования к среде

- **ОС:** Linux (ядро).
- **Компилятор:** g++ с поддержкой C++14.
- **Библиотеки:** OpenSSL (`libssl-dev`) для хеширования MD5.
- **Сетевой протокол:** TCP/IP.

##  Файлы конфигурации

### 1. Файл базы клиентов `vcalc.conf`

**Формат:** текстовый файл, каждая строка содержит пару `логин:пароль`.

**Расположение по умолчанию:** `/home/25pil08@ibst.psu/vcalc.conf`

**Пример содержимого:**
```text
user:P@ssW0rd
admin:secret123
testuser:testpass
```

**Требования:**
- Файл должен существовать до запуска сервера.
- Формат строки: `ID:пароль` (без пробелов вокруг двоеточия).
- Файл должен быть в формате Unix, без символов `\r`.
- Загружается сервером один раз при старте.

### 2. Файл журнала `vcalc.log`

**Назначение:** запись информации об ошибках и событиях работы сервера.

**Расположение по умолчанию:** `/home/25pil08@ibst.psu/vcalc.log`

**Формат записи:**
```text
[YYYY-MM-DD HH:MM:SS] [УРОВЕНЬ] сообщение
```

**Уровни критичности:**
- `INFO` — информационные сообщения (успешное подключение, завершение сессии).
- `WARNING` — некритические ошибки (ошибка аутентификации, разрыв соединения).
- `CRITICAL` — критические ошибки (не удалось открыть сокет, загрузить БД).

**Пример содержимого:**
```text
[2026-11-06 14:23:01] [INFO] Client database loaded successfully
[2026-11-06 14:23:05] [INFO] Server started on port 33333
[2026-11-06 14:25:12] [INFO] Client connected
[2026-11-06 14:25:15] [INFO] Session completed successfully for user: user
[2026-11-06 14:25:15] [INFO] Client disconnected
```

## ️ Пользовательский интерфейс

Программа не имеет интерактивного интерфейса. Управление осуществляется исключительно через параметры командной строки.

### Таблица параметров

| Параметр | Описание | Обязательность | Значение по умолчанию |
|----------|----------|----------------|----------------------|
| `--db <файл>` | Путь к файлу базы клиентов | Нет | `/home/25pil08@ibst.psu/vcalc.conf` |
| `--log <файл>` | Путь к файлу журнала работы | Нет | `/home/25pil08@ibst.psu/vcalc.log` |
| `--port <число>` | Номер TCP-порта для прослушивания | Нет | `33333` |
| `-h`, `--help` | Вывод справки по использованию | Нет | — |

### Правила использования

- При запуске **без параметров** программа выводит справку и завершает работу.
- При запуске с параметром `-h` или `--help` выводится справка и программа завершает работу.
- Некритические ошибки **не приводят** к аварийному завершению программы.
- Программа не взаимодействует с пользователем в интерактивном режиме.

##  Варианты использования

### Вариант 1: Запуск с параметрами по умолчанию
```bash
./server
```
Сервер использует БД и лог по путям, указанным в ТЗ, и слушает порт 33333.

### Вариант 2: Запуск с указанием своих файлов и порта
```bash
./server --db ./conf/vcalc.conf --log ./logs/vcalc.log --port 8080
```
Сервер использует локальные файлы конфигурации и слушает порт 8080.

### Вариант 3: Вывод справки
```bash
./server --help
# или
./server -h
```
Выводит информацию о доступных параметрах и завершает работу.

### Вариант 4: Типичный сценарий работы с клиентом
```bash
# Терминал 1: запуск сервера
./server --db ./conf/vcalc.conf --log ./logs/vcalc.log --port 33333

# Терминал 2: запуск клиента (пример)
./client_uint16 -H MD5 -S s
```
Клиент подключается, проходит аутентификацию, передает векторы и получает результаты вычислений.
